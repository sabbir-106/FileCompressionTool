## Week 8 — Duplicate File Detection and Archive Management

Implemented duplicate file detection using SHA-256 hashing.

Added a Duplicate Check feature to compare two files and determine whether they contain identical data.

Implemented Archive Manager for managing ZIP archives.

Added View Archive feature to display the files stored inside a ZIP archive.

Added Delete Archive feature to remove unwanted ZIP archives with user confirmation.

### Week 8 Features

- Duplicate file detection
- SHA-256 file comparison
- ZIP archive content viewing
- ZIP archive deletion
- Basic archive management
